# TaskFlow — Next.js (TP4)

TaskFlow refait avec Next.js (App Router) : routes par dossiers, données lues sur le serveur, composant client pour les filtres, écrans de chargement et 404.

## Lancement

```bash
npm install
npm run dev
```

http://localhost:3000

## Mise en ligne

```bash
npm run build
vercel deploy --prod
```
